# Garáž

Hra pro předškoláky na telefon: stavění aut z dílů, omalovánky s auty a dopravními značkami, učení čísel 1–10 a česká abeceda.

Hrát: https://michalondracekbt.github.io/garaz/

Na iPhonu otevři odkaz v Safari → Sdílet → Přidat na plochu. Na Androidu v Chromu → ⋮ → Přidat na plochu.

## Statistiky

Apka posílá anonymní statistiky hraní (které obrazovky a funkce se používají, postup v %, země a město podle připojení). Neukládá jména ani IP adresy, jen náhodné ID zařízení v prohlížeči.
